업무지원 현황 개선 시범 대시보드 구축 계획(안)

교육용 합성데이터 기반 시범 구축 후 실제 운영 적용 여부 검토

1 추진 배경 및 현황

  • 월간 보고자료 작성에 많은 시간이 소요된다는 의견이 제기됨.
  • 요청 처리상태를 통일하고, 긴급도가 높은 미완료 건을 우선 확인할 필요가 있음.
  • 실제 운영 전 교육용 시범 화면을 제작하고 결과 검토 후 적용 여부를 결정하기로 함.

! 의사결정이 필요한 사항

교육용 합성데이터를 활용한 시범 대시보드 제작을 추진하고, 시범 결과 검토 후 실제 운영 적용 여부를 별도 결정할지 여부
실제 운영 전환 시 일정·담당자·예산은 별도 검토 필요

2 주요 추진내용

시범 구축교육용 합성데이터 기반 대시보드 제작
상태관리접수 / 진행중 / 완료 / 보류 기준 적용 검토
우선관리긴급도 ‘상’ + 미완료 건 우선 확인
개인정보실제 개인정보 미사용
운영검토시범 결과 후 실제 적용 여부 결정

4 기대효과

  • 요청 처리현황의 일관된 관리방식 검토
  • 긴급 미완료 건 우선 확인 지원
  • 월간 보고자료 작성 지원 가능성 확인
정량적 효과는 근거자료가 없어 추가 확인 필요

5 추가 확인사항

서비스 전환 일정 운영 담당자 소요예산 대시보드 세부 항목 시범 결과 평가기준
현재 실제 서비스 전환 일정과 운영 담당자는 미정이며, 예산도 확인되지 않음.
작성 원칙 · 확인되지 않은 예산·일정·담당자·성과수치는 임의로 기재하지 않음 · 시범 단계는 실제 개인정보를 포함하지 않는 교육용 합성데이터 활용
